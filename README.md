# ホップスター ―8つの星の王国―

ブラウザーで遊べる3Dアクションゲームです。走って、跳んで、ブロックを下から突いてパワーアップしながら、8つの王国・全32ステージ（1-1〜8-4）を進みます。

**遊ぶ：https://ryu4649ww.github.io/hopstar/** （ログイン不要。PC・スマホ縦横どちらでも遊べます）

## 操作
| 動き | PC | スマホ |
|---|---|---|
| 移動 | WASD／矢印 | 左下のスティック |
| ジャンプ（水中では泳ぐ） | Space | A |
| ダッシュ | Shift | B |
| 火の玉（ファイアモード） | F | 🔥 |
| カメラ | Q／E・ドラッグ | 画面右上をなぞる |
| ポーズ | Esc | Ⅱ |

## 遊びの要素
- ？ブロックを下から突くと、コイン・ハートの実（一撃耐える元気モード）・ファイアベリー（火の玉が撃てる）・きらきら星（無敵）が出ます。
- 面の種類：地上・地下・空中（台だけ）・水中（泳ぐ）・城（ボス）。各ワールドの4面目でボスを倒すと「星のかけら」。
